# HLC Mobile A+ Sprint Program

Parent blueprint: `docs/mobile/HLC_MOBILE_A_PLUS_BLUEPRINT.md`

Execution order:
1. Sprint 1 — Shell + Home + Universal Search
2. Sprint 2 — Work + Quick Actions + Gestures
3. Sprint 3 — Network + Map + Filters
4. Sprint 4 — Community + Communications
5. Sprint 5 — Offline + Drafts + Saved State
6. Sprint 6 — Analytics + Professional Admin
7. Sprint 7 — Full-route iPhone QA + Performance

Rule: each sprint gets an isolated exact head, automated verification, rendered mobile QA and physical iPhone visual QA where presentation or interaction changed. A sprint does not advance with known regressions in completed A+ behavior.
