# HomeLead Connect — Legacy / Uploaded Evidence Reconciliation

Status: ACTIVE RECONCILIATION RULE

Reconcile supplied historical HomeLead Connect evidence against current HomeLead Connect/HCX authority. Historical material strengthens the active E2E build; it does not restart or redirect it.

## Governing rule

**Current confirmed authority wins every conflict.**

Do not resurrect superseded architecture, branding, visual decisions, release SHAs, historical production state, staged architecture, or obsolete implementation merely because they appear in an older package.

Extract still-valid requirements, regression expectations, missing workflow/CRM/automation coverage, asset provenance, accessibility expectations and functional boundaries into the current E2E Control Matrix, Test Matrix, Coverage Register and Exception Ledger.

Preserve protected functionality. Continue autonomously. Only unresolved consequential owner decisions enter the Exception Ledger.

## Evidence dispositions

### Canonical governance package
Use architecture boundaries, AI responsibility separation, anti-fabricated-data requirements, and the rule that runtime/repository claims must be verified rather than trusted from historical documentation. Older branding/logo definitions cannot override current locked HomeLead Connect authority.

### Master Context Pack
Use primarily as a completeness checklist for CRM architecture, sales processes, lead lifecycle, automation architecture, database schema, roles, SOPs, reporting, integrations, security, onboarding and knowledge base. Cross-check these against the current Control Matrix; do not restore superseded staged architecture.

### Public Front Door TSX
Visual/reference evidence only. Preserve its functional-boundary intent around routes, authentication, RPCs, forms, analytics, billing, permissions and submission handlers. Do not import obsolete imagery/design choices as current implementation.

### Menu recertification package
Regression evidence. Preserve useful Chromium/WebKit, multi-route/multi-viewport, keyboard, focus, touch-target, link-destination, SVG/text contrast and network-blocking expectations. Historical candidate/production SHAs are not current release authority.

### Official logo package
Asset-provenance evidence. Verify the currently locked official circular master logo and favicon/app-icon derivatives trace to approved authority rather than recreated/generated marks. Never generate a substitute logo.

### Visual handoff and Professional Pathway reference
Keep in the visual-evidence pool for intent/regression comparison. Current September 21 visual authority wins on conflict.

## Excluded personal material

Personal résumé/employment/contact material is not product-build evidence and must not be added to the HomeLead Connect repository, build context, Control Matrix, Test Matrix, Coverage Register, or implementation artifacts.

## Evidence handling

Historical documentation may establish intent or a test expectation, but does not establish current runtime truth. Verify current repository/runtime behavior before making implementation or release claims.

A useful legacy capability receives a current disposition and canonical home before obsolete presentation is retired.
