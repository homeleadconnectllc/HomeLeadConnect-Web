# HomeLead Connect — Complete Design Coverage Map

Status: GOVERNING INVENTORY / RECONCILIATION AUTHORITY  
Public naming: HomeLead Connect. “HCX” remains internal shorthand only.

## Governing completion rule

Visual completion is not a route count. Every destination, navigation entry, submenu, tab, setting, action, contextual control, drawer, modal, mobile surface, permission/entitlement state, and system state must have an intentional home in a reusable screen family.

No capability is considered visually complete because its backend exists. No page is complete while its important actions lead to dead ends, ambiguous homes, or unrelated settings surfaces.

### Communication authority

Phone, SMS, email, and contact methods are not buried under generic settings. Contact identity, consent, provider readiness, delivery evidence, conversation association, and follow-up are one end-to-end design track.

Client UI may prepare and validate a destination, but provider transmission destinations remain server/compliance resolved where governed. Communication history must preserve subject, channel, direction, purpose, provider/evidence source, outcome/status, timestamp, conversation/record association, and follow-up context where applicable.

## Coverage ledger fields

Every implementation/design audit row should resolve:

- Destination/surface name
- Portal/workspace
- Navigation home and parent
- Master screen family
- Desktop treatment
- Mobile treatment
- Tabs/subnavigation
- Primary and secondary actions
- Context menus/drawers/modals
- Data/system of record
- Role/permission authority
- Entitlement
- Personal vs organization vs HomeLead Connect-managed control
- Phone/SMS/email implications
- Consent/legal implications
- Empty/loading/error/offline states
- Audit/history requirements
- Current implementation status
- Evidence/test coverage
- Gap/repair disposition

## Definition of visually complete

HomeLead Connect is visually complete only when the coverage ledger shows that every intended capability has a named destination or contextual surface, every meaningful action has a destination and state response, shared capabilities use coherent families instead of duplicate one-off designs, desktop/mobile behavior is accounted for, permission and entitlement boundaries are visible, communications are end-to-end coherent, and all critical system states are intentionally designed and tested.
