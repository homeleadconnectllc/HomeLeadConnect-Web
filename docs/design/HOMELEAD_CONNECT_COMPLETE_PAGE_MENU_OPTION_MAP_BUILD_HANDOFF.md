# HomeLead Connect — Complete Page / Menu / Option Map Build Handoff

Status: ACTIVE BUILD REQUIREMENT  
Scope: Global — public site + authenticated platform + every portal/workspace  
Public name: HomeLead Connect. HCX is internal shorthand only.

## Governing requirement

This is implementation scope, not merely documentation. Reconcile against current verified implementation, current governance/specification, useful CRM/SaaS and automation capability, visual authority, Mobile A+ architecture, and working routes/records/workflows/permissions/integrations. Preserve working capability; repair, consolidate, relocate, or complete rather than duplicating. Newer locked authority wins on conflict.

Every meaningful capability must resolve through four connected maps:

1. **Page Map** — where the user goes.
2. **Menu Map** — how the user discovers/navigates to it.
3. **Option Map** — what the user can do there.
4. **State Map** — loading, empty, unavailable, restricted, offline, failed, complete, awaiting action and other non-default states.

A backend capability alone is not a complete design. No visible control may be a decorative fake or unexplained dead end.

## Execution sequence

Inventory → reconcile implementation → classify families → map navigation → map options/actions → map states → map permissions/entitlements → identify genuine gaps → implement → render → interact → test → repair → retest → record evidence.

## Definition of done
