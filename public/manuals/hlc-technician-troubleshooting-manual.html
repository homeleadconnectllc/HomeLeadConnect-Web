Technician Troubleshooting Manual

Field and technical recovery guide for HomeLead Connect. Use this when an HLC page, device, communication path, workflow, document, or account behaves unexpectedly.

Print / Save as PDF

1. First rule: preserve the evidence

  1. Do not delete the affected record.
  2. Write down the page/route, approximate time, workspace, device, browser, and record ID if visible.
  3. Capture the exact error message. Do not include passwords, OTP codes, API keys, service-role credentials, card numbers, or private secrets in screenshots.
  4. Retry once after a normal refresh. If the issue repeats, stop repeating the same write action.

2. Login and access

If sign-in fails, confirm the correct HLC hostname, network connection, and Turnstile verification. Use password recovery rather than creating a duplicate account. Team members invited to a company should use the invitation flow so membership attaches to the intended workspace.

If a user sees the wrong workspace or receives permission errors, the owner/manager must verify Team membership and role. Never share credentials as a shortcut.

3. Workflow recovery

Open the Golden Workflow and identify the first incomplete canonical stage. Do not skip provider acceptance, appointment, completion, consent, or billing gates by directly editing downstream records. Record the blocker and escalate if the required transition is unavailable.

4. Call Center and Google Voice

HLC supplies customer context, compliance state, notes, outcomes, and follow-up. Google Voice supplies the live carrier call surface when that line is selected. On iPhone, initiate Google Voice-number calls from the Google Voice app. On Mac, keep voice.google.com signed in and notifications allowed. After the call, return to HLC and record the outcome.

HLC must never claim Answer, Hold, Transfer, Hang Up, recording, delivery, or inbound synchronization unless supported provider evidence exists.

5. Messaging and voice notes

Before automated outreach, verify consent and suppression state. For a voice note, allow microphone access, record a short test, play it back, then send. If recording fails, confirm browser microphone permission and input device. Do not treat a local recording as delivered until HLC records a successful send/persist result.

6. Photos, videos, and documents

Use clear, relevant media. For repair evidence: start with one wide context photo, then closer images of the issue, labels/model plates when safe, and any visible damage. For video: keep clips short, move slowly, narrate what area is being shown, and avoid unrelated private information. Never upload passwords, financial documents, IDs, or sensitive household information unless the specific HLC workflow explicitly requires and protects it.

If upload fails, confirm file type/size, network stability, and that the record belongs to the current workspace. Retry once; do not create duplicate records repeatedly.

7. AI agents

Kendrell, Dion, and Diamond assist with summaries, operations, and customer experience. If an agent fails, refresh once and use the underlying HLC record workflow directly. AI never overrides permissions, consent, legal requirements, payment state, or canonical workflow gates.

8. Billing

Do not manually mark a workspace paid because a user returned from Stripe Checkout. Entitlement must come from synchronized Stripe/webhook state. If billing looks wrong, preserve the Stripe customer/subscription identifiers and HLC workspace ID, then escalate.

9. Security incident

For suspected unauthorized access, exposed secrets, wrong-workspace data, unexpected billing, or automation operating outside policy: stop the affected action, preserve evidence, notify management, and avoid making broad production changes until the scope is understood.

10. Escalation package

Send: device + OS, browser, HLC route, time, workspace, record ID, exact error, expected result, actual result, whether one refresh/retry was attempted, and a redacted screenshot when useful.

Owner / platform escalation: HomeLead Connect LLC. Product and technical lead: Antoine Washington.

11. Recovery order

  1. Verify correct account/workspace.
  2. Verify connectivity and browser permissions.
  3. Refresh once.
  4. Check canonical HLC record state.
  5. Check workflow/automation status.
  6. Check provider surface (Google Voice/Stripe/etc.) only if relevant.
  7. Escalate with evidence instead of improvising database or permission changes.
